En-tête, pied de page, bouton du bas, chat : les textes présents sur toutes les pages. Les liens des menus et du pied de page se modifient dans Menus et liens.

Les textes affichés par le JavaScript du site : module de réservation, avis, formulaires, chat, bandeaux, popup. Les éléments entre accolades, comme {n}, sont remplacés par une valeur : gardez-les tels quels.

Les textes des données structurées lues par Google et les assistants IA : description de l’hôtel, équipements, restaurant et bars. Ils ne s’affichent pas sur les pages. Sans traduction prête, c’est l’anglais qui est repris, sinon le français. La structure se règle dans Réglages.

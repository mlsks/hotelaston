Pour découvrir le back-office : une visite guidée des écrans, puis une première modification, de la page jusqu’au site en ligne.

Visite guidée

Deux minutes : une bulle montre chaque entrée du menu et les boutons Prévisualiser et Publier, avec ce qu’on y fait. Flèches du clavier pour avancer, Échap pour quitter.

étape(s) sur faites

Cinq règles à retenir

  • Ce qui est enregistré n’est pas visible tout de suite sur le site : d’abord dans la prévisualisation, puis sur le site après Publier.
  • Les textes s’enregistrent dès qu’on quitte le champ (« Enregistré ✓ ») ; les fiches, bandeaux, popups et réglages ont un bouton Enregistrer.
  • Une page n’est publiée dans une langue que si tous ses textes y sont prêts : jamais de page à moitié traduite.
  • Les trois dernières versions publiées sont gardées : une erreur se répare avec Restaurer.
  • Le menu de gauche ne montre que les écrans permis par votre rôle ; sur un petit écran, il s’ouvre avec le bouton ☰.
